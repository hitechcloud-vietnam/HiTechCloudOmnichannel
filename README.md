## About

**HiTechCloudOmnichannel** is an open-source omnichannel marketing, customer engagement and AI automation platform developed under the **HiTechCloud** ecosystem.

This project is **inherited from and further developed from the open-source HiTechCloudOmnichannel project**.

HiTechCloudOmnichannel continues the original foundation while evolving the platform toward:

* AI-native customer engagement
* Omnichannel communication
* AI Sales automation
* AI Agents
* Marketing automation
* CRM and customer journeys
* Workflow automation
* MCP and AI tool integration
* Developer APIs
* Self-hosted and cloud deployments

The goal is to provide an open platform that businesses can deploy themselves instead of depending entirely on closed SaaS platforms.

---

## 🚀 Why HiTechCloudOmnichannel?

Modern businesses communicate with customers across many channels.

Instead of managing separate systems for every channel, HiTechCloudOmnichannel provides a unified platform for:

```text
Customer
   │
   ├── WhatsApp
   ├── Facebook
   ├── Instagram
   ├── TikTok
   ├── Telegram
   ├── Zalo
   ├── Email
   ├── Webchat
   └── API
          │
          ▼
┌───────────────────────────────┐
│     HiTechCloudOmnichannel     │
├───────────────────────────────┤
│ CRM                           │
│ Inbox                         │
│ Automation                    │
│ Flow Builder                  │
│ AI Agents                     │
│ Marketing                     │
│ Analytics                     │
│ API / MCP                     │
└───────────────────────────────┘
          │
          ▼
     Sales / Support
```

## 🚀 Quick Start

### Requirements

Recommended environment:

* Node.js 24+
* pnpm 10+
* PostgreSQL
* Redis
* Docker
* Docker Compose

Install dependencies:

```bash
pnpm install
```

Start development:

```bash
pnpm dev
```

Build:

```bash
pnpm build
```

Run lint:

```bash
pnpm lint
```

Fix formatting:

```bash
pnpm fix
```

Check circular dependencies:

```bash
pnpm check:circular
```

Check unused dependencies:

```bash
pnpm check:unused
```

---

## 🧪 Development

Run individual applications:

```bash
pnpm --filter builder dev
```

```bash
pnpm --filter worker dev
```

```bash
pnpm --filter realtime dev
```

CLI:

```bash
pnpm --filter hitechcloudomnichannel dev:cli
```

MCP:

```bash
pnpm --filter hitechcloudomnichannel-mcp dev:mcp
```

Database Studio:

```bash
pnpm --filter @hitechcloud.vn/database db:studio
```

> Some internal package names and commands may retain their original HiTechCloudOmnichannel naming during the transition. They can be progressively migrated to HiTechCloud naming without changing the underlying architecture unnecessarily.
